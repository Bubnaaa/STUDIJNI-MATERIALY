## 4. Aplikační SW - kancelářský, grafický, vývoj, multimediální

- Je programové vybavení počítače, které umožňuje uživateli vykonávat konkrétní užitnou činnost
## Kancelářský SW
- Slouží k tvorbě , úpravě a správě dokumentů, dat a prezentací běžných v administrativním prostředí
- Textové procesory - slouží k úpravě a formátování textu
	- Microsoft Word, Google Docs, LibreOffice
- Tabulkové procesory - určené pro výpočty, analýzu dat, tvorbu grafů a tabulek
	- Microsoft Excel, Google sheets
- Prezenční sw - nástroje pro vizuální doprovod výkladu, nebo přednášky
	- Microsoft PowerPoint, Google Slides, Canva
- Databázové systémy - pro lokální evidenci strukturovaných dat
	- Microsoft Access, LibreOffice Base

## Grafický SW 
### Rastrová grafika
- Obraz je složen z jednotlivých pixelů
- Vhodná pro fotografie a reálné snímky
- Formáty: JPEG, PNG, GIF, WEBP, TIFF
- Adobe Photoshop, GIMP

### Vektorová grafika
- Obraz je definován pomocí matematických křivek
- Neomezeně škálovatelná, bez ztráty kvality
- Formáty: SVG, AI, EPS, PDF
- Adobe Illustrator, Inkscape, CorelDRAW

## Vývojový SW

- Programy určené k psaní, testování, ladění a sestavování zdrojového kódu nových aplikací.

### IDE
-  Kompletní balík nástrojů pod jednou střechou (obsahuje textový editor kódu, překladač/interpret, debugger a správu projektů)
    
    -  Visual Studio, JetBrains prostředí (PyCharm, IntelliJ IDEA, WebStorm), Android Studio, Xcode
        
### Code Editory (Pokročilé textové editory): 
- Lehčí nástroje, které lze rozšířit pomocí pluginů
    
    -   Zástupci: Visual Studio Code, Sublime Text, Vim
        
-   **Související nástroje:**
    
    -   Verzovací systémy (VCS): Git (sledování změn v kódu, větvení, týmová spolupráce – např. GitHub/GitLab).

        

## 4. Multimediální software

- Aplikace určené k vytváření, úpravě, přehrávání a organizaci zvuku, videa a animací.

### Přehrávače (Playback):
    
  - VLC Media Player, PotPlayer, Spotify.
        
### Střih a úprava videa (NLE - Non-Linear Editing):
    
  - Adobe Premiere Pro, DaVinci Resolve, Final Cut Pro (macOS).
        
    -   Postprodukce & Efekty: Adobe After Effects.
        
### Editor zvuku (Audio Editing & DAW):
    
 -  Audacity, Adobe Audition.
        
  -  DAW (Digital Audio Workstation) pro tvorbu hudby: Ableton Live, FL Studio, Cubase, GarageBand.
