## Parametry
---

| Parametr |     **Význam**     |                     Funkce                     |
| :------: | :----------------: | :--------------------------------------------: |
|   `-a`   |      **all**       |    Všechny položky, včetně skrytých souborů    |
|   `-l`   |      **long**      |            Podrobný výpis informací            |
|   `-h`   | **human-readable** | Zobrazení velikosti v přehledné formě (MB, KB) |
|   `-r`   |    **reverse**     |                Obrácené řazení                 |
|   `-f`   |     **force**      |           Vynutí akci bez potvrzení            |
|   `-v`   |    **verbose**     | Vypíše detailní průbeh toho, co se právě děje  |
|   `-d`   |   **directory**    |          Označí, že se jedná o složku          |
